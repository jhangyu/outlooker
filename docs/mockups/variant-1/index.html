O
Outlooker

        
歡迎使用 Outlooker

        
    
        
    所有資料只存在這台電腦上，不需要帳號，也不會上傳。
    
      
    
      
    
      
    
        
    Outlooker 能做什麼
    
        
    秒級搜尋百萬封郵件依寄件者、收件者或內文片段搜尋，中文與英文都能部分比對。
    
        
    跨 PST 自動去重同一封郵件在多個 PST 中只存一次，並記錄每個出現位置。
    
        
    郵件原貌呈現HTML 經過清理，內嵌圖片轉為 WebP，閱讀時與 Outlook 一致。
    
        
    完全在本機資料庫隨程式啟動與關閉，不需要帳號，也不連線網路。
